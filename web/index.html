INSTALL IT

Run this one-line command to install both the CLI tool and extension:

Install the tap with Homebrew, then run the installer:

brew install Vatsal057/tap/safari-magic-ext

Download the package to inspect source code or install offline:

Download .magicext bundle
safari-magic-ext install ~/Downloads/package.magicext

CONTRIBUTE

Share your extension

Made something in Safari? Package it and send it in. A maintainer reviews every submission, then it appears in this gallery.

If you have the CLI installed, run:

safari-magic-ext submit

Or run this 1-step command (installs the tool and opens submission together):

curl -fsSL https://raw.githubusercontent.com/Vatsal057/safari-magic-extensions/main/install-cli.sh | bash -s -- submit
