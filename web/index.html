Share your extension

Made something in Safari? Package it and send it in. A maintainer reviews every submission, then it appears in this gallery.

In Finder, press Cmd+Shift+G and paste this path:

~/Library/Containers/com.apple.Safari/Data/Library/Safari/MagicExtensions

Then drag your extension folder (e.g. nightlife-24B7) into the dropzone below. We'll read the metadata and package it in your browser.

Submit to GitHub ↗

This opens a pre-filled issue form. Attach the downloaded and click Submit.

Paste this into Terminal. Installs the CLI, presents an interactive picker, packages the selected extension, and opens the GitHub submission form.

curl -fsSL https://raw.githubusercontent.com/Vatsal057/safari-magic-extensions/main/install-cli.sh | bash -s -- submit

Packages your extension, reveals the file in Finder, and opens a pre-filled submission form. The name picker is interactive if you omit the name.

safari-magic-ext submit
Prefer a pull request?

Drop the package into web/packages/, run python3 scripts/build_registry.py, and commit both the package and the regenerated catalog. CI validates the archive and checks the catalog is current.

Full details in the contributing guide ↗.

Packages are checked automatically for unsafe archive paths and required metadata. Please don't submit anything with tracking or obfuscated code.
