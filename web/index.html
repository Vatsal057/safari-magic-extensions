Safari Magic Hub

A small Mac app that browses this gallery and installs extensions for you. Free, and about 500 KB.

Download for Mac ↗
  1. 1

    Open the .dmg and drag the app to Applications

    The window shows you exactly where to drop it.

  2. 2

    Right-click the app and choose Open

    Only needed the first time. macOS warns because the app isn't notarized by Apple — see the note below.

  3. 3

    Allow Full Disk Access when asked

    System Settings → Privacy & Security → Full Disk Access. Safari keeps its extension list in a protected folder, so macOS requires this.

  4. 4

    Open the Community tab and click Install

    Safari restarts and your new tab page is live.

Why does macOS warn me about this app?

Notarizing an app requires a paid Apple Developer account, which this project doesn't have. The app is code-signed, and the full source plus the exact build script are in the repository, so you can inspect or rebuild it yourself.

Every release lists a SHA-256 checksum if you'd like to verify your download.

optional Prefer the Terminal? There's a command line tool too

One command installs safari-magic-ext. It runs on the Python that macOS already includes, so there is nothing else to set up.

curl -fsSL https://raw.githubusercontent.com/Vatsal057/safari-magic-extensions/main/install-cli.sh | bash

Then install anything by its ID, for example:

safari-magic-ext install hacker-news-minimal

The installer writes a single file to ~/.local/bin, verifies it runs, and does nothing else. Your Terminal also needs Full Disk Access.

Share your extension

Made something in Safari? Package it and send it in. A maintainer reviews every submission, then it appears in this gallery.

one command

If you have the CLI

This packages your extension, reveals the file in Finder, and opens a pre-filled submission form in your browser. Drag the file in and submit.

safari-magic-ext submit "Your Extension Name"
or do it by hand
01

Package it

Turn an installed extension into a shareable .magicext file. It lands in your Downloads folder.

safari-magic-ext pack "Your Extension Name"
02

Attach it

Open the submission form, fill in your name and the prompt you used, and attach the file. No git required.

Prefer a pull request?

Drop the package into web/packages/, run python3 scripts/build_registry.py, and commit both the package and the regenerated catalog. CI validates the archive and checks the catalog is current.

Packages are checked automatically for unsafe archive paths and required metadata. Please don't submit anything with tracking or obfuscated code.
